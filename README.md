# LERNO

## نسخه حساب کاربری

- ثبت‌نام با نام، شماره موبایل و رمز عبور
- تأیید خروج با پنجره اختصاصی داخل برنامه
- نگهداری شماره آخرین حساب برای ورود سریع‌تر
- نمایش یا پنهان‌کردن رمز عبور با دکمه چشم
- نمایش خطاهای فرم در خود LERNO
- نمایش فقط فرم ورود پس از ساخت اولین حساب
- دکمه تغییر حساب کنار شماره ذخیره‌شده
- آیکون چشم واضح برای نمایش و پنهان‌کردن رمز
- جداسازی اطلاعات هر حساب روی همان دستگاه
- خروج خودکار پس از ۱۰ روز عدم مراجعه
- آیکون جدید LERNO برای نصب روی موبایل
- آیکون تأییدشده برای آیفون، اندروید و مرورگر
- نمایش خوانای تکلیف، امتحان و پروژه داخل تقویم موبایل
- رنگ آبی برای تکلیف، صورتی برای امتحان و نارنجی برای پروژه
- بازه تقویم از شهریور ۱۴۰۵ تا اسفند ۱۴۰۷
- نمایش اطلاعات ثبت‌شده پروفایل و دکمه بزرگ «تغییر اطلاعات»
- برش، بزرگ‌نمایی و جابه‌جایی عکس پروفایل پیش از ذخیره
- نام نسخه‌دار آیکون‌ها برای جلوگیری از ماندن لوگوی قدیمی در کش موبایل

> این نسخه آفلاین است و کد پیامکی واقعی ارسال نمی‌کند. برای پیامک و همگام‌سازی چند دستگاه، اتصال به سرویس سمت سرور لازم است.

برنامه‌ریز فارسی دانش‌آموزی، آماده انتشار به‌صورت سایت و نصب روی صفحه اصلی موبایل.

## انتشار در GitHub Pages

1. همه فایل‌ها و پوشه‌های داخل این پوشه را در ریشه مخزن GitHub قرار دهید؛ خود فایل ZIP را به‌تنهایی آپلود نکنید.
2. شاخه اصلی مخزن باید `main` باشد.
3. در مخزن به `Settings → Pages` بروید.
4. زیر `Build and deployment`، گزینه `GitHub Actions` را انتخاب کنید.
5. پس از اجرای موفق workflow، لینک سایت در همان صفحه نمایش داده می‌شود.

آدرس معمول سایت به شکل زیر است:

`https://USERNAME.github.io/REPOSITORY/`

## افزودن به صفحه اصلی گوشی

- Android/Chrome: سایت را باز کنید و «Install app» یا «Add to Home screen» را بزنید.
- iPhone/Safari: دکمه Share را بزنید و «Add to Home Screen» را انتخاب کنید.

اطلاعات کاربر فعلاً داخل مرورگر همان دستگاه ذخیره می‌شود.
