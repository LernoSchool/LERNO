# LERNO

برنامه‌ریز فارسی دانش‌آموزی، آماده انتشار به‌صورت سایت و نصب روی صفحه اصلی موبایل.

## انتشار در GitHub Pages

1. یک مخزن جدید در GitHub بسازید و همه فایل‌های این پوشه را در ریشه آن قرار دهید.
2. شاخه اصلی مخزن باید `main` باشد.
3. در مخزن به `Settings → Pages` بروید.
4. زیر `Build and deployment`، گزینه `GitHub Actions` را انتخاب کنید.
5. پس از اجرای موفق workflow، لینک سایت در همان صفحه نمایش داده می‌شود.

آدرس معمول سایت به شکل زیر است:

`https://USERNAME.github.io/REPOSITORY/`

## افزودن به صفحه اصلی گوشی

- Android/Chrome: سایت را باز کنید و «Install app» یا «Add to Home screen» را بزنید.
- iPhone/Safari: دکمه Share را بزنید و «Add to Home Screen» را انتخاب کنید.

اطلاعات کاربر فعلاً داخل مرورگر همان دستگاه ذخیره می‌شود.
